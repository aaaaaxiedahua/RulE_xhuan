# RulE 三大创新点方案

面向当前 RulE 在规则筛选粗放、负采样噪声大以及打分器表达力不足等痛点，提出三项可落地的改进方案，覆盖 `config/topk`、`RuleDataset`/`KGETrainDataset` 与 `FuncToNodeSum`/`score_model` 三条主线。

## 1. Top-K 规则选择器
- **核心思路**：真正启用配置文件中的 `topk`，只保留对当前查询最有贡献的规则，减少噪声与推理时间。
- **实现步骤**  
  1. 在 `model.forward` 中对 `rule_count` 统计进行评分（可用支持度总和或 `add_ruleE_g` 得分）。  
  2. 按 `config/topk` 取前 K 条，若有效规则少于 K 则保持全量。  
  3. 对被裁剪规则记录统计，便于后续清洗或重新挖掘。  
  4. 当无规则可用时自动回退到 `compute_g_KGE`，保证预测稳定。
- **收益**：剪掉弱规则能提升 MRR/Hits，且推理复杂度从 O(全部规则) 降至 O(topk)。

## 2. 负对抗采样引擎
- **核心思路**：在保持原有腐蚀式负采样的前提下，引入“自对抗”权重，让模型把注意力集中在最难分的伪规则和伪三元组上，实现“负采样 + 难样本加权”一体化升级。
- **实现步骤**  
  1. **规则分支**：在 `RuleDataset` 中仍按“随机替换 body/翻转 head”生成候选负规则，但为每个候选记录 `RuleScore`。  
  2. **温度加权**：在 `PreTrainer.train_step` 内新增 `rule_adversarial_temperature`，对规则负样本得分做 `softmax(score/T)`（梯度截断）并作为权重乘到 `logsigmoid(-score)` 上。  
  3. **实体分支复用**：KGE 负样本已有自对抗机制，可共享同一温度或单独调参；同时支持开关 `rule_disable_adv`，方便回退到均匀权重。  
  4. **统计驱动**：将被 Top-K 多次淘汰、但得分高的规则标记为“高风险”，在下一轮负采样时优先生成它们的变体，形成闭环。  
- **收益**：自对抗可以自动拉高“似是而非”负例的梯度贡献，抑制易样本噪声；与 Top-K 剪枝结合，能显著增强规则嵌入与 KGE 表示的辨别力。

## 3. 自适应 MLP 推理头
- **核心思路**：升级 `FuncToNodeSum` + `score_model` 的结构，引入残差、注意力和正则化，使规则信号与实体嵌入更好融合。
- **实现步骤**  
  1. 在 `FuncToNodeSum` 中把 `rule_emb` 与 `rule_count` 拼接后送入多头注意力或轻量 GRU，学习规则体不同位置的重要性。  
  2. `score_model` 从两层扩展到 `[128, 128, 1]` 的残差 MLP，加入 LayerNorm 与 Dropout，并拼接当前关系 embedding 作为条件。  
  3. 对 `mlp_rule_feature` 加 L2 与对齐正则（靠近 `rule_emb`），Grounding 阶段允许其以较小 LR 微调。  
  4. 提供 `mlp_rule_dim` 自动调参：当规则体较长时动态增大维度，短规则则保持轻量。
- **收益**：更强的表达能力让剪枝后的高质量规则得到充分利用，推理头可根据关系特征自适应调权，最终在 Hits@1/3 上取得可观提升。

> 三项改进互相促进：Top-K 保证输入高质，动态负采样提供稳健训练信号，自适应 MLP 释放上限，可在现有代码结构中逐步落地验证。
