个负样本)详细步骤Step 1: 路径推导 (Body Calculation)沿着规则前提（Body）进行变换。初始：$Box_0 = (C_h, W_h)$第一跳 ($r_1$)：$Box_1 = \text{Transform}(Box_0, r_1)$第二跳 ($r_2$)：$Box_{Body} = \text{Transform}(Box_1, r_2)$产出：$Box_{Body}$ (预测区域)Step 2: 目标推导 (Head Calculation)沿着规则结论（Head）进行变换。单跳 ($r_{target}$)：$Box_{Head} = \text{Transform}(Box_0, r_{target})$产出：$Box_{Head}$ (理论基准区域)Step 3: 计算动态置信度 $w_i$ (Geometric Entailment)[方案 2 核心] 计算 $Box_{Body}$ 在 $Box_{Head}$ 中的包含率。计算交集盒 ($Box_{Inter\_Head}$)：$$\text{Min}_{IH} = \max(C_{Body}-W_{Body}, \ C_{Head}-W_{Head})$$$$\text{Max}_{IH} = \min(C_{Body}+W_{Body}, \ C_{Head}+W_{Head})$$若任意维度 $\text{Min}_{IH} > \text{Max}_{IH}$，则体积为 0。计算 $w_i$：$$w_i(h) = \frac{\text{Vol}(\text{Min}_{IH}, \text{Max}_{IH})}{\text{Vol}(Box_{Body}) + \epsilon}$$Step 4: 计算 Grounding 得分 $v_{rule}$计算 $Box_{Body}$ 与每个候选实体 $t \in E_{cand}$ 的重叠。循环计算 ($t$ in $E_{cand}$)：$$\text{Min}_{IC} = \max(C_{Body}-W_{Body}, \ C_{t}-W_{t})$$$$\text{Max}_{IC} = \min(C_{Body}+W_{Body}, \ C_{t}+W_{t})$$$$v_{rule}(h, t) = \text{Vol}(\text{Min}_{IC}, \text{Max}_{IC})$$Step 5: 融合得分$$S_{Rule}(h, t) = w_i(h) \times v_{rule}(h, t)$$三、 训练流程 (Training Pipeline)这是你最关心的部分，一定要分阶段，一定要有负样本。阶段 1：几何预热 (Warm-up Phase)目的：初始化 KGE，防止盒子坍缩，为规则计算提供几何基础。如果不做这一步，所有 $w_i$ 都会是 0。数据流：仅使用 KGE 分支，不加载规则。Step-by-Step：读取 Batch：获取一批真实三元组 $B = \{(h, r, t)_{pos}\}$.负采样 (Negative Sampling)：对每个 $(h, r, t)_{pos}$，随机从实体库中抽取 $k$ 个实体 $t'_{neg}$。构成负样本集：$\{(h, r, t')_{neg_1}, (h, r, t')_{neg_2}, ...\}$.前向传播 (Forward)：计算 $Box_{pred} = \text{Transform}(h, r)$。计算正样本得分：$score_{pos} = \text{Vol}(Box_{pred} \cap Box_{t_{pos}})$。计算负样本得分：$score_{neg} = \text{Vol}(Box_{pred} \cap Box_{t'_{neg}})$。计算损失 (Loss)：$$L_{Warmup} = -\log \sigma (\gamma - d(pos)) - \sum \log \sigma (d(neg) - \gamma)$$直白解释：拉大正样本重叠体积，压缩负样本重叠体积（让它们分离）。反向传播：更新所有 $C, W, \tau, \sigma$。阶段 2：联合训练 (Joint Training Phase)目的：引入规则，优化 $w_i$ 和最终推理能力。数据流：KGE + Rules 同时工作。Step-by-Step：读取 Batch：$B = \{(h, r, t)_{pos}\}$.负采样：同上，生成 $k$ 个负样本。计算 KGE Loss：同阶段 1，$L_{KGE}$。计算 Rule Loss：找到支持 $r$ 的所有规则 $\{R_1, R_2, ...\}$.对每个规则，计算 $w_i(h)$ 和 $v_{rule}(h, t_{pos})$.我们希望：如果是正样本，$w_i \times v_{rule}$ 越大越好。$$L_{Rule} = - \sum_{pos} \log (\sum_{Rules} w_i(h) \cdot v_{rule}(h, t_{pos}) + \epsilon)$$总损失：$L_{Total} = L_{KGE} + \lambda L_{Rule}$。反向传播：更新所有参数。四、 测试/推理流程 (Inference Phase)当模型训练完毕，进入 model.eval() 模式。输入查询：$(h, r_{target}, ?)$全量实体库：$E_{all}$ (假设有 10,000 个实体)详细步骤KGE 分支打分：计算 $S_{KGE}(h, t)$ for all $t \in E_{all}$。Rule 分支打分：检索出目标为 $r_{target}$ 的规则集。计算 $Box_{Body}$：对每条规则，计算出预测区域。空间筛选 (可选加速)：利用 $Box_{Body}$ 在 R-Tree 中查询，只取重叠的实体作为候选（如 50 个）。计算 $w_i(h)$：判断规则对当前 $h$ 的置信度。计算 Grounding：计算候选实体的重叠体积。得到 $S_{Rule}$。结果融合：$$S_{Final}(t) = S_{KGE}(t) + \beta S_{Rule}(t)$$排序输出：对所有实体按 $S_{Final}$ 降序排列。返回 Top 1, Top 10。
1. 场景设定 (The Setup)查询：(Alice, LivesIn, ?) —— Alice 住在哪里？真实答案：New York (纽约)。候选实体 ($t$)：我们要计算候选人 New York 的得分。2. 激活的三条规则 (The Rules)在这个知识图谱里，关于 LivesIn 有三条常见规则：规则 R1 (夫妻同住)：$Spouse(x, y) \wedge LivesIn(y, z) \to LivesIn(x, z)$逻辑：Alice 的老公住哪，Alice 就住哪。规则 R2 (工作地居住)：$WorksIn(x, z) \to LivesIn(x, z)$逻辑：Alice 在哪工作，她就住哪。规则 R3 (出生地居住)：$BornIn(x, z) \to LivesIn(x, z)$逻辑：Alice 生在哪，她就住哪。3. 并行推理过程 (Parallel Reasoning)现在的关键是：针对同一个头实体 Alice，这三条规则并行计算，分别给出 $w_i$ 和 $v_{rule}$。假设模型训练后的几何状态如下：Alice 的理论居住地 ($Box_{Head}$)：位于坐标 $[100, 100]$ (由 Alice + LivesIn 算出来的基准)。➤ 规则 R1 的计算流程 (夫妻同住)路径：Alice $\to$ 老公(Bob) $\to$ Bob的居住地(New York)。$Box_{Body\_R1}$：算出位置在 $[102, 98]$ (非常接近理论值)。$w_1$ (自信度)：$Body$ ($[102, 98]$) 与 $Head$ ($[100, 100]$) 高度重叠。$w_1 = 0.9$ (模型认为：这条规则对 Alice 非常适用)。$v_{rule\_1}$ (命中 New York)：$Body$ ($[102, 98]$) 与候选人 New York ($[100, 100]$) 重叠。$v_{rule\_1} = 1.0$。R1 得分：$0.9 \times 1.0 = \mathbf{0.9}$。➤ 规则 R2 的计算流程 (工作地)路径：Alice $\to$ 工作地(Manhattan) $\to$ Manhattan所在城市(New York)。$Box_{Body\_R2}$：算出位置在 $[95, 105]$ (也在纽约范围内，稍微有点偏)。$w_2$ (自信度)：$Body$ 与 $Head$ 重叠度不错，但不如夫妻关系那么紧密。$w_2 = 0.7$。$v_{rule\_2}$ (命中 New York)：$Body$ 与候选人 New York 重叠。$v_{rule\_2} = 1.0$。R2 得分：$0.7 \times 1.0 = \mathbf{0.7}$。➤ 规则 R3 的计算流程 (出生地) —— 冲突发生路径：Alice $\to$ 出生地(Paris)。$Box_{Body\_R3}$：算出位置在 $[500, 500]$ (巴黎的坐标，离纽约十万八千里)。$w_3$ (自信度)：$Body$ (巴黎) 与 $Head$ (纽约理论区) 毫无重叠。模型通过几何计算发现：Alice 搬家了，她的出生地规则失效。$w_3 \approx 0.0$。$v_{rule\_3}$ (命中 New York)：$Body$ (巴黎) 与候选人 New York 无重叠。$v_{rule\_3} = 0.0$。R3 得分：$0.0 \times 0.0 = \mathbf{0.0}$。4. 分数聚合 (Aggregation)现在我们有了三条规则对同一个候选人 New York 的打分。最终得分通常是求和（或者加权求和）。$$S_{Rule\_Total}(Alice, New York) = \sum_{i=1}^3 (w_i \cdot v_{rule\_i})$$计算过程：来自 R1 (夫妻)：+ 0.9 (主力证据)来自 R2 (工作)：+ 0.7 (辅助证据，加强了置信度)来自 R3 (出生)：+ 0.0 (噪声，被自动过滤)总分：$$S_{Final} = 0.9 + 0.7 + 0 = \mathbf{1.6}$$5. 对比：如果候选人是 Paris (巴黎)为了让你看清 $w_i$ 的威力，我们看看如果候选实体是错误答案 Paris 会发生什么。针对 R1 (夫妻)：$Box_{Body}$ 指向纽约。命中 Paris 吗？不命中。得分 = $0.9 \times 0 = 0$。针对 R2 (工作)：$Box_{Body}$ 指向纽约。命中 Paris 吗？不命中。得分 = $0.7 \times 0 = 0$。针对 R3 (出生)：$Box_{Body}$ 指向 Paris。命中 Paris 吗？ 命中了！ ($v_{rule} = 1.0$)。但是！ 我们之前算过，对于 Alice 来说，R3 的 $w_3 = 0$ (因为出生地和目前居住地不符)。得分：$w_3 \times v_{rule} = 0 \times 1.0 = \mathbf{0}$。Paris 总分：$0 + 0 + 0 = \mathbf{0}$。核心亮点：即便规则 R3 准确地找到了 Paris，但因为模型判定“出生地规则对 Alice 不适用 ($w_3=0$)”，所以 Paris 依然没有得分。这就是 Box-RulE 方案 2 最大的优势——抗噪声。6. 完整的公式表达对于一个查询 $(h, r_{target}, ?)$ 和一个候选实体 $t$，最终分数为：$$Score(h, t) = \underbrace{S_{KGE}(h, t)}_{\text{基础得分}} + \beta \sum_{k=1}^{M} \underbrace{w_k(h)}_{\text{第k条规则自信度}} \times \underbrace{Vol(Box_{Body}^{(k)} \cap Box_t)}_{\text{第k条规则的Grounding}}$$$M$：是激活的规则总数（本例中 $M=3$）。$\sum$：体现了“众人拾柴火焰高”。多个规则指向同一个答案，分数会叠加，超过单一规则的得分。

方案 B —— 体积正则化 (Volume Regularization)核心目的：防止盒子“坍缩成点”（导致梯度消失）或“膨胀成宇宙”（导致精度丧失）。直观理解：给盒子加一个**“弹性约束”**。想象盒子是由橡皮筋做的，如果它缩得太小，橡皮筋会把它撑开；如果它撑得太大，橡皮筋会把它勒紧。1. 为什么要加 Log？(The Math Trick)你可能会想，直接惩罚体积 $Vol$ 不行吗？$$L = (Vol - \mu)^2$$不行。数值稳定性问题：在高维空间（比如 128维），体积是 128 个宽度的乘积：$Vol = \prod_{i=1}^{128} w_i$。如果 $w_i \approx 0.1$，则 $Vol \approx 10^{-128}$ (下溢，变成0)。如果 $w_i \approx 2.0$，则 $Vol \approx 10^{38}$ (上溢，变成无穷大)。梯度问题：直接对乘积求导，梯度极不稳定。正确做法：在 Log 域操作$$L_{Reg} = (\log(\text{Vol}) - \mu)^2$$利用对数性质：$\log(\prod w_i) = \sum \log(w_i)$。我们将乘法变成了加法，数值范围瞬间变得非常可控。2. 公式推导我们定义每个维度的宽度为 $w_i$。$$Loss_{Vol} = \lambda \cdot \left| \left( \sum_{i=1}^d \log(w_i + \epsilon) \right) - \tau \right|$$$\lambda$ (权重)：比如 $0.001$。不要让它干扰主任务。$\tau$ (目标体积)：通常设为 $0$。意味着我们希望 $\sum \log w_i \approx 0$，即平均每个维度的宽度在 $1.0$ 左右。这是一个非常健康的数值。$\epsilon$：防止 $\log(0)$。
