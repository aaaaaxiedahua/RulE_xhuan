⏺ 规则置信度的不确定性建模 - 详细展开

  一、核心动机

  1.1 现有问题分析

  RulE当前的规则置信度计算（论文Equation 6）：
  w_i = γ_r - d(r_i1, ..., r_il+1, R_i)

  存在的问题：
  - ✗ 确定性标量：每个规则只有一个固定的置信度值
  - ✗ 无法表达不确定性：模型不知道自己对规则可靠性的把握程度
  - ✗ 训练样本不足时过度自信：对罕见规则可能给出高置信度但实际
  不可靠
  - ✗
  无法量化规则质量的方差：不同数据集/场景下规则可靠性差异大

  举例说明：
  规则1: born_in(x,y) ∧ city_of(y,z) → nationality(x,z)
    - 训练集中有1000个支持样本
    - 成功率: 95%
    - 当前RulE给出: w_1 = 0.85（但不知道这个0.85有多可靠）

  规则2: works_in(x,y) ∧ located_in(y,z) → lives_in(x,z)
    - 训练集中只有10个支持样本
    - 成功率: 80%
    - 当前RulE给出: w_2 = 0.75（看起来比规则1差一点）
    
  问题：规则2的置信度应该有更高的不确定性！

  ---
  二、技术方案设计

  2.1 不确定性建模框架

  采用变分贝叶斯方法，将规则置信度建模为高斯分布：

  w_i ~ N(μ_i, σ_i²)

  其中：
  - μ_i: 规则置信度的期望（类似原始w_i）
  - σ_i²: 规则置信度的方差（表示不确定性）

  2.2 详细实现

  Step 1: 修改规则置信度计算网络

  class UncertaintyRuleConfidence(nn.Module):
      def __init__(self, hidden_dim, rule_dim):
          super().__init__()
          self.hidden_dim = hidden_dim

          # 原始规则嵌入
          self.rule_emb = nn.Parameter(torch.randn(num_rules,
  rule_dim))

          # 新增：置信度均值网络
          self.mu_network = nn.Sequential(
              nn.Linear(rule_dim + hidden_dim, 256),
              nn.ReLU(),
              nn.Linear(256, 128),
              nn.ReLU(),
              nn.Linear(128, 1)
          )

          # 新增：置信度方差网络（输出log(σ²)保证正性）
          self.logvar_network = nn.Sequential(
              nn.Linear(rule_dim + hidden_dim, 256),
              nn.ReLU(),
              nn.Linear(256, 128),
              nn.ReLU(),
              nn.Linear(128, 1)
          )

      def forward(self, rule_idx, relation_embs):
          """
          Args:
              rule_idx: 规则索引
              relation_embs: 规则体中的关系嵌入 [r_i1, ..., 
  r_il, r_il+1]
          Returns:
              mu: 置信度均值
              sigma: 置信度标准差
          """
          # 获取规则嵌入
          R_i = self.rule_emb[rule_idx]  # [rule_dim]

          # 聚合规则体中的关系嵌入
          rel_agg = torch.sum(torch.stack(relation_embs[:-1]),
   dim=0)  # [hidden_dim]

          # 拼接特征
          features = torch.cat([R_i, rel_agg], dim=-1)  # 
  [rule_dim + hidden_dim]

          # 计算均值和方差
          mu = self.mu_network(features)  # [1]
          logvar = self.logvar_network(features)  # [1]
          sigma = torch.exp(0.5 * logvar)  # 转换为标准差

          return mu.squeeze(), sigma.squeeze()

  Step 2: 重参数化采样（Reparameterization Trick）

  在训练时使用重参数化技巧保证梯度可以反向传播：

  def sample_confidence(mu, sigma, num_samples=1):
      """
      使用重参数化技巧采样规则置信度
      w = μ + σ * ε, 其中 ε ~ N(0,1)
      """
      epsilon = torch.randn(num_samples, device=mu.device)
      w_samples = mu + sigma * epsilon  # [num_samples]
      return w_samples

  # 使用示例
  mu_i, sigma_i = confidence_model(rule_idx, relation_embs)

  # 训练时：采样多次取平均
  w_samples = sample_confidence(mu_i, sigma_i, num_samples=5)
  w_i = w_samples.mean()

  # 推理时：直接使用均值
  w_i = mu_i

  Step 3: 构建软多热编码

  修改原始RulE的soft multi-hot encoding（论文Section 3.2）：

  def construct_soft_multihot(query, activated_rules, 
  confidence_model):
      """
      Args:
          query: (h, r, ?)
          activated_rules: 激活的规则列表及其支持路径数
          confidence_model: 不确定性置信度模型
      Returns:
          v: 软多热编码 [num_rules]
      """
      v = torch.zeros(num_rules)

      for rule_i, num_paths in activated_rules:
          # 计算规则置信度的均值和方差
          mu_i, sigma_i = confidence_model(rule_i, ...)

          # 训练时采样，推理时用均值
          if training:
              w_i = sample_confidence(mu_i, sigma_i,
  num_samples=5).mean()
          else:
              w_i = mu_i

          # 置信度 × 路径数
          v[rule_i] = w_i * num_paths

      return v

  Step 4: 不确定性正则化损失

  添加两个正则化项来约束不确定性：

  def uncertainty_regularization(mu_list, sigma_list, 
  rule_support_counts):
      """
      Args:
          mu_list: 所有规则的置信度均值 [num_rules]
          sigma_list: 所有规则的置信度标准差 [num_rules]
          rule_support_counts: 每个规则在训练集中的支持数 
  [num_rules]
      """
      # 1. 信息瓶颈正则化：防止方差塌缩到0
      #    鼓励模型保持一定的不确定性
      kl_divergence = 0.5 * torch.sum(
          mu_list**2 + sigma_list**2 -
  torch.log(sigma_list**2) - 1
      )

      # 2. 数据依赖的不确定性：支持样本少的规则应该有更高方差
      #    λ(n) = λ_0 / (1 + log(n))  # n是支持数
      target_sigma = lambda_0 / (1 +
  torch.log(rule_support_counts + 1))
      sigma_matching_loss = torch.mean((sigma_list -
  target_sigma)**2)

      return kl_divergence + sigma_matching_loss

  Step 5: 完整训练流程

  def train_step(batch_triplets, batch_rules, 
  confidence_model, kg_model):
      # ===== 1. KGE Loss (原始RulE的triplet loss) =====
      kge_loss = compute_kge_loss(batch_triplets)

      # ===== 2. Rule Embedding Loss =====
      rule_loss = 0
      mu_all, sigma_all = [], []

      for rule_i, (r_body, r_head) in enumerate(batch_rules):
          # 获取关系嵌入
          body_embs = [kg_model.relation_emb[r] for r in
  r_body]
          head_emb = kg_model.relation_emb[r_head]

          # 计算不确定性置信度
          mu_i, sigma_i = confidence_model(rule_i, body_embs +
   [head_emb])
          mu_all.append(mu_i)
          sigma_all.append(sigma_i)

          # 采样置信度
          w_samples = sample_confidence(mu_i, sigma_i,
  num_samples=5)
          w_i = w_samples.mean()

          # 规则距离损失（原始RulE的公式）
          d_r = torch.norm(
              torch.sum(torch.stack(body_embs), dim=0)
              + kg_model.rule_emb[rule_i]
              - head_emb
          )

          # 加权损失（置信度低的规则损失权重小）
          rule_loss += torch.sigmoid(w_i) * (gamma_r - d_r)

      # ===== 3. Uncertainty Regularization =====
      uncertainty_loss = uncertainty_regularization(
          torch.stack(mu_all),
          torch.stack(sigma_all),
          rule_support_counts
      )

      # ===== 4. Total Loss =====
      total_loss = kge_loss + alpha * rule_loss + beta *
  uncertainty_loss

      return total_loss

  3.2 评估指标

  标准指标：
  - MRR, Hits@1, Hits@3, Hits@10

  新增不确定性指标：
  # 1. 校准误差 (Calibration Error)
  #    模型预测的不确定性与实际错误率是否匹配
  def calibration_error(predictions, uncertainties, 
  ground_truth):
      bins = np.linspace(0, 1, 10)
      calibration = 0

      for i in range(len(bins)-1):
          # 找到不确定性在[bins[i], bins[i+1]]范围的样本
          mask = (uncertainties >= bins[i]) & (uncertainties <
   bins[i+1])
          if mask.sum() == 0:
              continue

          # 计算该区间的平均错误率
          actual_error = (predictions[mask] !=
  ground_truth[mask]).float().mean()
          expected_error = uncertainties[mask].mean()

          calibration += abs(actual_error - expected_error)

      return calibration / (len(bins) - 1)

  # 2. 不确定性与规则质量的相关性
  #    好的规则应该有低不确定性，差的规则应该有高不确定性
  def uncertainty_quality_correlation(rule_uncertainties, 
  rule_accuracies):
      return -np.corrcoef(rule_uncertainties,
  rule_accuracies)[0, 1]

  五、进阶扩展方向

  5.1 异方差建模（Heteroscedastic Modeling）

  不同关系的规则可能有不同的不确定性模式：

  # 为每个关系类型学习不同的方差
  class RelationAwareUncertainty(nn.Module):
      def __init__(self):
          self.relation_sigma = nn.Embedding(num_relations, 1)

      def forward(self, rule_idx, relation_embs, 
  query_relation):
          mu = self.mu_network(...)

          # 基础方差 + 关系特定方差
          base_logvar = self.logvar_network(...)
          relation_logvar =
  self.relation_sigma(query_relation)

          sigma = torch.exp(0.5 * (base_logvar +
  relation_logvar))
          return mu, sigma

  5.2 证据理论集成（Evidential Deep Learning）

  用Dirichlet分布建模类别概率的不确定性：

  # 输出Dirichlet分布参数α
  alpha = evidence_network(rule_features) + 1  # 
  [num_candidates]

  # 预测概率
  prob = alpha / alpha.sum()

  # 不确定性度量
  uncertainty = num_candidates / alpha.sum()  # 越小越确定

  七、论文撰写要点

  7.1 创新点阐述

  "Unlike prior work that uses deterministic confidence 
  scores, we model rule reliability as a Gaussian distribution
   to capture both the expected quality (mean) and epistemic 
  uncertainty (variance). This enables the model to 
  automatically downweight unreliable or low-support rules 
  during inference."

  7.2 理论分析

  可以证明这等价于对规则置信度做变分推断：

  最大化 ELBO:
    L = E_{w~q(w|μ,σ)}[log p(y|w)] - KL(q(w|μ,σ) || p(w))
    
  其中：
  - q(w|μ,σ): 变分后验（我们的高斯分布）
  - p(w): 先验（标准正态分布）
  - p(y|w): 似然（规则推理结果）
